# Figure Assets

Place thesis figures in this directory and reference them from chapter files:

```tex
\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.8\textwidth]{thesis/assets/figures/example.png}
  \caption{Figure caption}
  \label{fig:example}
\end{figure}
```

Use stable filenames and avoid spaces where possible.
